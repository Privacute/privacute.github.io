01 · Case study

Clinical GRC Assessment

A full risk assessment of a fictional outpatient clinic after a breach, with every finding mapped to a verified SCF control.

Findings are stored as structured data, not prose. Before any report is written, the pipeline checks every control ID against the live SCF catalog (1,468 controls, SCF 2026.2). An invalid ID stops the run.

The repository shows it rejecting PHY-03, an ID that follows SCF naming conventions but does not exist. A human skimming the report would pass it. The pipeline does not.

Scoring uses a 5x5 likelihood-by-impact matrix. The AI narrative layer is optional, off by default, and only restates facts the pipeline has already verified.

The clinic is fictional. The methodology, control mapping, scoring and tooling are my own work.

03 · Tool

Privacy Pulse

A short survey that adapts to the respondent's role and shows a practice where its patient-data handling stands.

It scores each respondent and writes every answer to a Google Sheet the practice owns. It runs on GitHub Pages and Google Apps Script, so there is no third-party form service and nothing to pay for.

The survey tells respondents what is stored, where it goes, and how to have it deleted, and it asks them not to enter patient information.

04 · Prototype

Case Manager Action Queue

A decision-support prototype that turns a mental-health caseload into a ranked list of overdue and open coordination steps.

The first version invented its own thresholds, including a 0 to 10 confidence score. The second removed every rule the source process chart does not prescribe.

Steps with no deadline in the chart show as Open, never as overdue. It does not measure patient confidence, because no source prescribes a way to. "No open steps" never means "patient safe".

Three role views (case manager, consultant, admin). Fake data only. Runs in the browser with no build step.
